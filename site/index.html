    03 / INSTALLATION

    Cài đặt đơn giản, minh bạch.

    01

    Tải bộ cài phù hợp

    Windows tải file EXE; Android tải APK. Kiểm tra đúng nền tảng và phiên bản trước khi mở tệp.

    02

    Xác nhận quyền cài đặt

    Windows có thể yêu cầu xác nhận từ hệ thống. Android có thể yêu cầu cho phép trình duyệt cài ứng dụng từ nguồn này.

    03

    Giữ ứng dụng cập nhật

    Windows và Android có thể kiểm tra manifest mới. Android sẽ mở tệp APK để bạn xác nhận cài bản cập nhật; không tự cài lén trong nền.
